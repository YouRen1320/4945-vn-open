# 《4945区：先上号再说》设计系统（已归档）

> **归档说明（2026-08-05）**：本稿是早期设计草案，其靛紫 `#8b7cf6` 色板与现行实现不符。
> 现行唯一有效的设计基线是 `../4945区视觉小说/MASTER.md`（酒红 `#b65f7f` 色板，与
> `game/src/styles/tokens.css` 一致）。本文件仅作历史参考保留，不要再依据它开发界面。

> 本文件是视觉与交互的单一真值来源。UI/UX Pro Max 的检索结果用于确定电影化深色、移动优先、可访问性与低动态原则；色彩和中文字体根据已确认的两张概念图重新校准。

## 1. 产品体验

- 产品：移动优先的 Web 视觉小说，桌面端增强为 16:9 舞台。
- 气质：半写实黑色幽默群像剧；深夜群聊、系统通知与梦幻战斗意象并置。
- 东方感：使用弹幕式轨迹、结界纹样、段落式音乐推进和“符卡感”章节标题，但不复用任何既有作品素材。
- 核心操作：点击/空格推进，关键选择必须明确显示行动、收益线索和风险线索。

## 2. 色彩令牌

| 角色 | 颜色 | 用途 |
|---|---|---|
| 深墨 | `#070916` | 页面底色 |
| 夜蓝 | `#0d1230` | 舞台与面板底色 |
| 靛紫 | `#8b7cf6` | 主操作、焦点、玩家侧 |
| 樱粉 | `#f39ac7` | 关系、私聊、情绪线索 |
| 暖金 | `#e8bc78` | 关键节点、历史锚点、CTA |

| 次文 | `#c5bfd8` | 辅助文字，仍满足可读对比 |

所有组件只引用语义变量，不在组件内散落十六进制颜色。功能状态不能只依赖颜色，还要配合文字或 Lucide 线性图标。

## 3. 字体

- 标题：`"Songti SC", "Noto Serif CJK SC", STSong, serif`，用于章节名和结局名。
- 正文：`-apple-system, BlinkMacSystemFont, "PingFang SC", "Microsoft YaHei", sans-serif`。
- 数字与系统记录：`"SFMono-Regular", Consolas, monospace`。
- 不依赖远程字体，确保国内服务器、PWA 离线和弱网环境一致。
- 手机正文 16px 起，行高 1.65；选项不低于 15px；小标签不低于 12px。

## 4. 移动布局

- 基准宽度：375px；断点 640 / 900 / 1200px。
- 使用 `100dvh`，固定控件加入 `env(safe-area-inset-*)`。
- 竖屏：背景全屏裁切，对话区占底部约 42%，选择最多占可视区 60% 并可纵向滚动。
- 横屏/桌面：舞台限制在 16:9，状态栏在上、命令栏在右或底部，不遮挡文本。
- 所有可点击区域至少 48×48px，间隔至少 8px，不依赖悬停。

## 5. 组件规则

- 主按钮：暖金或靛紫实底，同一屏只出现一个最强主操作。
- 选择卡：半透明夜蓝，左侧序号、正文、后果提示分层；按下时只改变亮度与边框，避免布局抖动。
- 对话框：深色磨砂表面、1px 高光边框、轻微上边缘辉光；透明度必须保证背景再亮也可读。
- 模态面板：手机从底部进入，桌面居中；必须有明确关闭按钮和 Escape 路径。
- 结构图标统一使用 Lucide 2px 线性图标，不使用 Emoji 充当按钮。
- 群聊场景保留玩家头像的杂糅感，只统一圆形外框、组织标签和昵称排版。

## 6. 动效与音效

- 微交互 160–240ms；章节转场不超过 420ms。
- 只动画 `opacity` 与 `transform`，不以宽高变化制造重排。
- 弹幕粒子是低透明背景层，不遮挡正文；每屏最多两类主动动画。
- 完整支持 `prefers-reduced-motion: reduce`，关闭打字机、漂浮和视差效果。
- 按钮反馈在 100ms 内出现；音乐和音效均可独立静音。

## 7. 可访问性与键盘

- 正文对比度至少 4.5:1，焦点轮廓至少 2px。
- Enter/Space 推进，数字键或方向键选择，H 打开历史，S 保存，L 读档，Escape 返回。
- 背景图提供语义描述；纯装饰粒子 `aria-hidden`。
- 打字文本区域使用适当的 `aria-live`，但自动/跳过时不连续轰炸读屏器。
- 浏览器缩放不禁用；200% 字号时仍能滚动完成所有选择。

## 8. 性能与离线

- 首屏只预载标题图、当前场景和必要头像；其他图片按章节懒加载。
- 图片构建为 WebP/AVIF 衍生资源并保留源图；声明宽高或 `aspect-ratio` 防止布局偏移。
- PWA 缓存应用壳和完整第一季素材；首次缓存时显示进度和弱网说明。
- 不从第三方 CDN 加载运行必需资源。

## 9. 上线前检查

- 375px 竖屏、667×375 横屏、768px 平板、1440px 桌面均无横向滚动。
- iPhone 安全区和底部手势条不遮挡按钮。
- 所有触控目标 ≥48px；所有图标按钮有 `aria-label`。
- 键盘可完成一整条路线；减少动态模式完整可玩。
- 存档、导入导出、自动、跳过、历史、图鉴均可恢复并给出反馈。
- 亮色背景场景中的对白仍满足对比度。
