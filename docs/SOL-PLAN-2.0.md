# 《4945区》2.0 Sol 方案：第一季章节回放候选收口

> 状态：功能已在本地源码中实现；当前按“实现候选”管理，尚不能仅凭源码版本号认定为公开稳定发布。
>
> 剧情定位：不新增剧情，完整保留第一季 2026-07-17 至 2026-07-28 的既有事实与节点。
>
> 前置：schema4 / v4 第一季基线。
>
> 后继：[2.1 第一季组织与成员补遗](./SOL-PLAN-2.1.md)。

## 1. 目标与范围

2.0 只把已经实现的“标准章节回放与路线沙盒”收口成证据完整、版本一致、可回滚的发布候选。当前阶段不因新路线图而临时追加剧情，否则会把已完成的隔离回放验收重新打开。

玩家侧交付：通关任一组织结局后，从标题页进入 31 个标准入口，在不改动正常存档和收藏的前提下重玩第一季共通序章或五条组织路线的任一章节。

## 2. 已实现能力

- 31 个类型化检查点：1 个共通序章，五条路线各 6 个章节；
- 章节选择界面、路线解锁、玩家名和六组组织名沙盒输入；
- 章节回放与关系回忆共用通用隔离会话；
- 回放不写存档、不合并收藏、不发奖励、不解锁结局；
- 回放期间阻止保存、读取、导入、新游戏和嵌套回放；
- 正常结束或主动退出回到章节选择，刷新后回到标题页；
- 第一季节点、结局、CG ID 和 schema4 保持不变。

这些能力仍须以最终 acceptance 逐项复核；本方案不把 release note 中的自述替代为独立验收证据。

## 3. 当前不一致

| 项目 | 当前证据 | 收口要求 |
|---|---|---|
| 应用版本 | package、状态常量、发布说明为 `2.0.0` | 保持一致或明确回退 |
| Service Worker | 缓存键仍为 `4945-v1.7.1-r1` | 发布构建最后同步为唯一 2.0 缓存键 |
| 线上状态 | 旧路线图只证明 v1.7.1 线上稳定 | 未做公网验证前不得写“2.0 已上线” |
| 验收文件 | 有 release 文档，无独立 V2.0 acceptance | 新增逐项证据和未验证项 |
| 自动验证 | typecheck、303 项单测、普通资产审计已通过 | 收口时重跑并记录退出状态 |
| E2E | 有章节回放规格，现有发布文档称未实际执行 | 安装可用浏览器后执行，不以“可发现”代替通过 |
| v1.8 素材 | 4/36 ready，32 pending | 明确延期/目标版本/取消，不冒充 2.0 正式资产 |

## 4. 发布收口任务

### 4.1 版本与文档

- 新增 `game/docs/V2.0-ACCEPTANCE.md`；
- 核对 package、锁文件、运行时常量、发布说明、页面版本和 Service Worker；
- 明确记录“本地候选”“预发布验证”“公网稳定”三个状态，不混用；
- 更新两份路线图时，只写已有证据支持的状态。

### 4.2 回放验收

- 31 个入口 ID 唯一、节点存在、章节与路线匹配；
- 每个检查点至少存在一条到第一季制作人员页的合法路径；
- 正常结束、主动退出、异常、刷新四类路径均保持所有存档槽、收藏和正常会话不变；
- 关系回忆迁移后行为与原合同一致；
- 手机竖屏、手机横屏、桌面、键盘、焦点和读屏流程可完成。

### 4.3 素材处置

2.0 不接入新的 v1.8 图片。现有 32 项 pending 必须在清单中明确标为延期并写明后续归属；2.0 继续使用已登记 fallback。该延期不等于图片验收通过，也不能让 `audit:assets:final` 伪通过。

## 5. 完成标准

1. `npm run typecheck`、`npm test`、`npm run audit:assets`、`npm run build`、`npm run test:e2e` 全部实际执行并通过。
2. 31 个检查点与四类隔离退出路径全部有自动证据。
3. `game/docs/V2.0-ACCEPTANCE.md` 区分自动、人工、离线和公网验证。
4. 版本号、发布说明和 Service Worker 缓存键一致。
5. 真实安装、离线重启、旧缓存升级和回滚通过。
6. 若执行公网发布，发布地址、构建 ID、时间和回滚目录有记录；否则状态保持“候选”。
7. 第一季五条正常新游戏路线、关系回忆、旧存档读取和现有收藏无回归。

## 6. 迁移与回滚

2.0 不升级存档结构，继续写 `4945-vn:v4:save:*` 和既有收藏键。发布采用不可变目录与 `current` 原子切换；回滚指向最后一个已验证构建即可，不能删除玩家数据或 v1.8 待办清单。

## 7. 兼容性妥协

- 标准回放使用登记的标准状态，不复原玩家当时的精确选择。
- 六组自定义组织名只在本次沙盒内生效。
- v1.8 未完成视觉继续使用既有 fallback，明确延期而非伪装完成。

## 8. 有意不做

- 不新增第一季或第二季剧情。
- 不升级 schema、不加入个人章节快照或二周目数值继承。
- 不生成、替换或接入图片。
- 不顺手改造第一季内容目录。

## 9. 退出闸门

只有版本证据一致、E2E 与离线更新真实通过、独立 acceptance 完成后，2.0 才可标记为稳定；否则 2.1 可以继续做只读内容设计，但不得建立在“2.0 已公开发布”的假设上。
