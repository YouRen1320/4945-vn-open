## 1. 目标与范围

2.1 不是第二季准备文档，也不是纯审计版本。它交付一组可玩的第一季补遗，优先补足组织路线与成员行动之间的因果：事件为什么发生、成员为什么选择支持或离开、玩家的治理决定如何改变局部过程。

推荐内容结构：一个补遗入口，加五条现有组织路线各一篇完整短篇。每篇只处理该路线审计中优先级最高的一个因果缺口，不按相同节点数强行扩写。

## 2. 为什么先补这一层

当前 766 个节点中，第一阶段和续篇关系内容合计 372 个，已经接近内容图的一半；组织路线共 347 个且分布差异明显。继续平均增加恋爱日常会进一步挤压主线，而单纯把短路线补到和二组一样长也没有叙事价值。

2.1 采用“戏剧缺口优先”而非“节点配额优先”：只有缺少动机、冲突、玩家能动性或后果的地方才补；已有完整因果的路线可以用更短的成员视角篇完成。

## 3. 剧情单元合同

### 3.1 共通入口

- 标题页或通关后内容中心提供“第一季补遗”入口；
- 玩家完成对应组织路线任一组织结局后，解锁该路线补遗；
- 入口明确标注这是补充叙事，不改变原路线结局或原存档结果；
- 补遗使用隔离会话，结束后返回补遗列表。

### 3.2 五篇路线补遗

每篇必须包含：

1. 一个来自现有 2026-07-17 至 2026-07-28 时间线的明确缺口；
2. 一名或一组组织成员的可理解立场；
3. 玩家能够采取的治理、沟通、资源或关系行动；
4. 至少一个产生可见即时差异的选择；
5. 对该局部冲突的收束和成员后续态度；
6. 与既有路线事实一致的返回点，不改写原组织结局。

补遗可以采用玩家当时未看见的成员视角，但不能声称掌握当前资料没有确认的现实事实。必要的戏剧连接必须标为 `adapted` 或 `fictional`。

### 3.3 内容优先级

内容审计按以下顺序选题：

1. 关键组织转折缺少直接因果；
2. 重要成员行动只在结果中出现，缺少动机或反应；
3. 玩家重大选择缺少局部后果；
4. 路线中段存在明显跳时或情绪断层；
5. 已有完整主线但缺少成员余波。

关系内容只有在它直接改变本篇组织冲突时才能进入，不新增独立约会、告白或关系续篇。

## 4. 内容与 ID 规则

- 新节点统一使用 `s1x-` 前缀，提示词使用 `S1X-`；
- 既有第一季节点、选择、结局和 CG ID 不修改、不重排；
- 每篇维护独立入口、完成节点、消费的既有事实、局部 flags 和素材引用；
- 补遗选择只改变当前隔离篇章，不回写组织主线状态；
- 完成记录可以追加到既有收藏的 seenNodes / ending IDs，不升级存档 schema；
- 若补遗需要引用争议事实，场景卡必须有 `confirmed/adapted/fictional` 标签和来源说明。

## 6. 支撑实现

- 把通用回放会话扩展为 `season1-supplement` 类型，复用现有隔离与退出路径；
- 建立补遗注册表、解锁规则和内容图验证；
- 为补遗完成节点和收藏解锁增加幂等测试；
- 不为了补遗拆分整个第一季目录，也不提前实现第二季 schema5。

## 7. 验收标准

1. 五条组织路线各有一篇可从入口完成并返回的补遗；篇幅可以不同，但每篇的戏剧缺口均被关闭。
2. 每篇至少一个选择有不同即时结果，不存在只有措辞变化却宣传为路线分支的伪选择。
3. 所有新节点使用 `s1x-`，既有节点与结局 ID 零改动。
4. 补遗正常结束、主动退出、异常和刷新均不改变来源存档、组织结局、关系值或既有历史。
5. 每个场景有事实标签，未出现任何未经确认的 2026-07-28 后事实。
6. 五条第一季主路线、31 个章节回放和关系回忆完整回归。
7. 本版提示词、素材清单和正式图片验收完成，`targetRelease = 2.1` 的 pending 为零。
8. 类型检查、单测、内容图、构建、E2E、离线和目标设备人工验收通过。

## 8. 迁移与回滚

本版保持 schema4。补遗只追加新 ID 和收藏项，回滚到 2.0 时这些收藏 ID 被旧版本忽略但保留；重新进入 2.1 后恢复可见。不得删除或改写玩家原第一季档。

## 9. 兼容性妥协

- 补遗采用隔离短篇，不会把新局部选择反向写入已经完成的主线结局。
- 路线篇幅不追求相等，接受由实际叙事缺口造成的长度差异。
- 为保护事实边界，部分连接只能明确标为架空改编，不能伪装成历史记录。

## 10. 有意不做

- 不开始第二季，不创建 post-2026-07-28 正式事实。
- 不新增独立恋爱篇、攻略对象或关系结局。
- 不升级 schema、不迁移收藏、不做按季懒加载。
- 不补齐与本版戏剧缺口无关的所有背景设定。

## 11. 退出闸门

五篇补遗、连续性审计、正式素材和全量回归全部通过后，2.1 才可发布。2.2 的 canon 设计可以只读并行，但不得借 2.1 内容偷渡第二季事实。
