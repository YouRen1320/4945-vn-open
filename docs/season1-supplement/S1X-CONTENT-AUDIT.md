## 1. 二组路线（route2.ts · 江南）

**叙事弧**：玩家接任二组首领，承接因辰逸禁言事件信任崩塌的继承型组织，主线是重建秩序并消化高层换血（岸卸任、时与大古升层）与六组残部并入。

**优先级① — 时 7/19 加入二组，动机空白**
- 缺口：节点 `r2-02-shi-arrives` 以"系统通知式转组"呈现，未交代**时为何选二组而非留下/去别处**。`r2-14-council-choice` 时升层是二组新班子成型关键一步，但"二组给了什么五组没给的"根因悬空。
- 成员：时、温陷（五组）、玩家。
- 为何可补：二组合法性来自"能不能吸住人"，时不交代动机 = "为什么值得跟"命题悬空。
- 玩家可行动：否（动机主体在时）——但补遗可由**玩家作为二组首领与时的对谈框架**承载，玩家选择"如何接住时"决定时的坦诚度与后续态度（满足 §3.2 #3/#4）。

**优先级② — 六组残部 AVUCII 来意未展开**
- 缺口：`r2-28-remnants` / `r2-28a-life-fragment` 玩家有 3 选项，但 AVUCII"为什么愿意并、为什么由她来谈"在二组视角只在结果呈现。
- 成员：AVUCII、玩家（可行动：追问来意）。

**优先级③ — 玩家选择死 flag（无后果）**
- 缺口：`anForcedToStayTemporarily`（`r2-13-an-resigns` 勉强留岸选项 set 后无读取）、`promisedShiPromotion`、`muteHandledByRule`/`supportedChenyiMute`、`releasedFullContext`/`keptContextInternal`、`org2Apologized`、`plannedHoldFireTwo`/`plannedFortressFeint`/`negotiatedWithWenxian`、`acceptedOrg6Remnants` 等，经 Grep 全文件确认仅 `effects` 写入、无 `condition`/`when` 读取。最尖锐：`anForcedToStayTemporarily` 使"岸是否被强留"无叙事后果。
- 成员：岸、takemehand、温陷、AVUCII。玩家可行动：是（本身即玩家选择）。

**优先级④ — 7/21→7/23 两天跳时**
- 缺口：`r2-22-xilufei-stays`（希露菲 7/21 退出）→ `r2-23-war-letter`（7/23 告白战书）之间，二组内部消化"管理层换血后第一周"无节点。
- 成员：夏娜、时、大古、玩家（可行动）。

**优先级⑤ — 时升层后内心余波缺收尾**
- 缺口：`r2-14-council-choice` 后至 `r2-30*` 夜话，时"站队二组后的内心 / 与原五组温陷的关系"未在二组线收尾（可行动：夜话找时）。

**本路线最高优先级单一缺口**：优先级①（时加入动机）。戏剧尖锐度上 `anForcedToStayTemporarily` 死 flag 亦极值得补，作为备选或合并进二组篇的玩家选择后果分支。

## 2. 三组路线（route3.ts · 抚梅观清雪）

**叙事弧**：心跳成瘾接任三组首领，以"吸收不是拥有"为组织哲学，承接将进酒、告白、OguriC 的转组与温陷的部分合并谈判。

**优先级① — 告白 7/28 转一组，直接原因从未公开**
- 缺口：`r3-19-gaobai-leaves` 原文"别问我为什么，我也只来得及把高层名单改回去"；`r3-22-bond-heartbeat` 同样回避。基线文档标注为"高优先级待确认项"，且告白 7/26 才进三组、两天后即走，动机完全空白。
- 成员：告白、心跳成瘾、玩家。
- 玩家可行动：是（作为三组首领追问告白去留）。

**优先级② — 时离开五组（三组视角） / 将进酒接纳反应**
- 缺口 A：`r3-02-shi-transfer` 在三组视角只是"不完整截图"里的离开，动机未展开。
- 缺口 B：`r3-11-jiangjinjiu-arrives` 将进酒动机已核对，但"作为原四组高层如何被三组接纳的心理余波"只在入组节点呈现。
- 成员：时、将进酒、玄末（四组）、心跳成瘾。玩家可行动：是。

**优先级③ — 玩家重大选择缺后果**
- 该优先级在本路线**无明显结构性缺口**（合并谈判、告白离开均进入后续分支/结局路由）。个别回应选项仅在数值层回弹，属可接受设计。

**优先级④ — 7/27→7/28 盟友危机情绪断层**
- 缺口：`r3-18-other-reorganizations`（系统简报四组危机，7/27）直接跳 `r3-19-gaobai-leaves`（7/28），三组内部对"砚秋水可能离开"的共情反应无节点。
- 成员：心跳成瘾、砚秋水（四组）、玩家（可行动）。

**优先级⑤ — 温陷余波缺收尾**
- 缺口：`r3-16-merger-offer` 温陷来谈合并后，其在三组线的余波（是否常来、两组边界日常）无收尾节点（夜话 `r3-20*` 无温陷专属段）。玩家可行动：是（夜话找温陷）。

**本路线最高优先级单一缺口**：优先级①（告白转组动机）——三组最核心、基线明确待确认、且跨 route3/4/5 同源。

## 3. 四组路线（route4.ts · 天上白玉京）

**叙事弧**：砚秋水立四组、把首领交玩家，以"账本与规则能否约束首领"贯穿——收 takemehand、将进酒因与玄末冲突离开、火2 五组战败、稀有饰品分配危机中砚秋水去留。

**优先级① — 砚秋水为何创立四组、为何把首领给玩家**
- 缺口：`r4-00-founded` 仅完成"天上白玉京"命名 + 空白账本仪式，未交代"五大组织成型后为何还要开第六个、为何首领是玩家"。序章 `r4-01-allocation-promise` 的账本承诺部分代偿"为何是规则型组织"，但"为何立组/为何是你"仍空。
- 成员：砚秋水、玩家。玩家可行动：是（追问砚秋水"你为什么立这个组、为什么是我"）。

**优先级② — 将进酒离开，玄末之缘反应缺失**
- 缺口：`r4-10c-xuanmo-dispute` / `r4-10d-jiangjinjiu-leaves` 给了将进酒动机与玄末"push back"立场，但**玄末"为何如此强烈反对将进酒替二组收话"的深层心理、将进酒走后玄末"自己把同伴逼走"的反应无节点**。镜头直接到 `r4-11-alliance-offer`（7/24）。
- 成员：玄末之缘、将进酒、玩家。玩家可行动：是（冲突中/后调解或追问玄末）。

**优先级③ — 序章治理承诺未兑现**
- 缺口：`r4-01-allocation-promise` 三选项中仅 `org4PublicLedger` 在 `r4-16-first-allocation` 被读取；`org4LeaderDiscretion`、`org4MemberVote` set 后无后续读取。此外 `r4-05-response` 的 `org4JoinedFlameWar`（参战）仅改 org2 关系、无叙事分支。
- 成员：砚秋水、华月、玩家。玩家可行动：是。

**优先级④ — 7/21→7/23 两天跳时**
- 缺口：`r4-10b-xilufei-leaves`（7/21）→ `r4-10c-xuanmo-dispute`（7/23）之间，四组内部消化"将进酒要走"的酝酿、玄末与将进酒私下关系缺失，冲突"前夜"空白。

**优先级⑤ — 成员余波**
- 该优先级在本路线**无明显缺口**（砚秋水去留、华月接任、takemehand/玄末夜话均已收尾）。

**本路线最高优先级单一缺口**：优先级①（四组成立动机）。戏剧尖锐度上玄末对将进酒离开的反应（优先级②）更值得补，可作为四组篇的玩家选择后果分支。

## 6. 选题与分工原则（供冻结评审）

1. **每篇只补一个最高优先级缺口（§3.3 编号最小者 = ①）**，避免强行扩写。
2. **同源事件不重复编造**：时转组 = 二组①（获得方）+ 五组①（失去方）双视角；告白转组 = 三组① 主补，五组/四组不再另立。
3. **玩家可行动性兜底**：编号①缺口中"时动机"主体在 NPC，补遗统一用"玩家作为首领的对话框架"承载——玩家选择"如何接住/追问/接纳"决定 NPC 坦诚度与即时态度差异，满足 §3.2 #3/#4（至少一个可见即时后果选择）。
4. **事实边界**：所有补遗节点日期落在 07-17~07-28；不引用、不新造 07-28 后"正式确认事实"；跨路线戏剧连接标 `adapted`/`fictional`。
5. **返回点一致**：每篇以"返回补遗列表"结束，不回写组织主线状态、关系值或既有结局。
