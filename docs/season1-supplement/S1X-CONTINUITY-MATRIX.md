## 隔离不变量（全局）

1. **既有节点零改动**：`r2-*`~`r6-*` 所有节点、选择、结局、CG ID 不修改、不重排。
2. **局部 flag 不泄漏**：所有 `s1x0X_*` flag 仅存于隔离补遗会话，结束/退出/刷新/异常均不写回 `useGameStore` 主线状态、关系值或 `4945-vn:v4:save:*`。
3. **收藏仅追加**：补遗完成节点（如 `s1x01_done`）可追加到既有收藏 `seenNodes` / 结局 IDs；不升级 schema（仍 schema4 / v4）。
4. **返回点一致**：每篇以"返回补遗列表"结束，不进入任何主线后续节点。
5. **事实边界**：仅引用 2026-07-17~07-28 既有事实；不引入 07-28 后正式事实、不引入第二季。

- **消费既有事实**：`r2-02-shi-arrives`（时加入）、`r2-14-council-choice`（时升层）— 仅引用。
- **局部 flags**：`s1x01_shiTrust`（low/mid/high）、`s1x01_done`。

- **隔离保证**：时升层结果以主线 `r2-14` 为准，本篇 `s1x01_shiTrust` 不影响升层。
- **跨篇约束**：时动因须与 S1X-04 统一（"二组给了确定性"）。

### S1X-02 · 三组《两次转组的人》

- **跨篇约束**：告白转组动机仅在 S1X-02 主补；S1X-04 五组侧不另立。

### S1X-03 · 四组《空白账本之前》
