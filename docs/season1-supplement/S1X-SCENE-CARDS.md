## S1X-01 · 二组《值得跟的人》

**路线**：二组·江南（继承型组织）
**锚定缺口**：`r2-02-shi-arrives` 时以系统通知式转组登场，缺"二组凭什么值得跟"的因果（优先级①）。
**事实标签**：`adapted`（时转组事件本身为 route 确认事实，本篇为其成员视角补全）。
**消费既有事实**：`r2-02-shi-arrives`（时加入）、`r2-14-council-choice`（时升层）——仅引用，不改写。
**成员可理解立场**：时——五组成立当天即走，不是因为讨厌温陷，而是五组当时连"自己要成为什么"都没定下来；二组那边，玩家刚接任就着手重建秩序、肯给"被辰逸事件伤过的人"一个位置，这是时看重的"确定性"。

**玩家可行动（对话框架内）**：玩家作为二组新首领，与刚转来的时第一次单独对谈。三选一姿态：
- **A 给位置**："二组现在缺能扛事的人，你来得正好。" → 时感到被需要。
- **B 给真话**："我知道你从五组来，那边发生了什么？" → 时感到被信任。
- **C 给边界**："先观察一阵，证明你能留再说。" → 时感到被审视。

**至少一个可见即时后果选择**：上述 A/B/C 在篇内即时改变时的反应文本与**篇内局部 flag `s1x01_shiTrust`**（low/mid/high），并影响收束段时说的"我留下"还是"我再看看"。此 flag **仅存于本隔离篇章**，不写回主线。

**局部收束与成员后续态度**：无论姿态，时都确认"先留下"；差异体现在他对玩家的私下评价（高信任=主动聊二组规划；低信任=客气但保留）。返回点：补遗列表。

**设计约束**：不回写 `r2-14-council-choice` 的升层结果；时升层仍以主线为准；本篇不新增任何二组主线节点。

**建议节点骨架（s1x-）**：
```
s1x01-entry        → 二组·夜谈开场（玩家独白：时来了）
s1x01-shi-opens   → 时简短自述转组（adapted，不揭全因）
s1x01-player-posture → 三选一（A/B/C，set s1x01_shiTrust）
s1x01-shi-react   → 按 trust 分支（low/mid/high 三段文本）
s1x01-close       → 时确认留下 + 返回补遗列表（set s1x01_done）
```

## S1X-02 · 三组《两次转组的人》

**路线**：三组·抚梅观清雪（吸收不是拥有）
**锚定缺口**：`r3-19-gaobai-leaves` 告白 7/28 转一组，直接原因从未公开（优先级①；基线待确认项）。
**事实标签**：`confirmed`（告白转一组为 route 确认事实）+ `adapted`（去留动机为戏剧化补全）。
**消费既有事实**：`r3-16a-oguri-gaobai-arrive`（告白 7/26 进三组）、`r3-19-gaobai-leaves`（7/28 转一组，原文"别问我为什么，我也只来得及把高层名单改回去"）、`r3-22-bond-heartbeat`——仅引用。
**成员可理解立场**：告白——他两次转组都不是"背叛"，而是每次都先把自己放进一个"能让他安心写东西的地方"。进三组是因为心跳成瘾说"人来人走不等于组织死亡"；再走是因为一组那边有个他没法拒绝的具体理由（**本篇统一落地：一组给了他一个"只属于写作者、不被任何组织裹挟"的承诺**，属 adapted 补全，不声称为历史记录）。

**玩家可行动**：玩家作为三组首领，在告白提交转组前最后一次对话。两选一：
- **A 放行**："你来了又走，三组都接得住。" → 告白释然，留下一段手写告别。
- **B 挽留**："至少说清楚为什么。" → 告白说出一组的承诺（adapted 动因落地）。

**至少一个可见即时后果选择**：A/B 即时改变告白的临别文本与**篇内 flag `s1x02_gaobaiReasonKnown`**（true/false），并影响返回补遗列表时三组首领（玩家）的独白（懂了 vs 仍存疑）。flag 仅存本篇。

**局部收束与成员后续态度**：告白转一组结果不变（与主线一致）；差异在玩家作为首领是否"理解了组织的容器本质"。返回点：补遗列表。

**设计约束**：不改写 `r3-19-gaobai-leaves` 的转组结果；不新增三组主线节点；一组的具体承诺仅作 adapted 戏剧连接，不在主线建立为事实。

**建议节点骨架（s1x-）**：
```
s1x02-entry        → 三组·告白来辞行
s1x02-player-choice → A 放行 / B 挽留（set s1x02_gaobaiReasonKnown）
s1x02-gaobai-leaves → 按 choice 分支文本（含 adapted 动因）
s1x02-close        → 玩家独白差异 + 返回补遗列表（set s1x02_done）
```

## S1X-03 · 四组《空白账本之前》

**路线**：四组·天上白玉京（账本与规则）
**锚定缺口**：`r4-00-founded` 仅完成命名 + 空白账本仪式，缺"为何立第六个组织、为何首领是玩家"（优先级①）。
**事实标签**：`confirmed`（砚秋水立四组、交首领给玩家为 route 确认事实）+ `adapted`（立组动因补全）。
**消费既有事实**：`r4-00-founded`（天上白玉京命名、空白账本）、`r4-01-allocation-promise`（账本承诺序章）——仅引用。
**成员可理解立场**：砚秋水——五大组织成型后，她看到的是"每个组都在用故事绑架人"；她开第四组（注：叙事内为"白玉京"，时间线上为对前五组的回应性组织），不是要更大，而是要一个"首领也得被账本管着"的反例。选玩家当首领，是因为玩家在辰逸禁言事件后表现出"愿意把规则写下来、而不是靠威信压人"。

**玩家可行动**：玩家追问砚秋水"你为什么立这个组、为什么是我"。两选一：
- **A 问立组动因**："为什么要再开一个？" → 砚秋水讲"反绑架"动因（adapted）。
- **B 问为何是你**："为什么是我当首领？" → 砚秋水讲"你愿意写规则"的信任依据（confirmed 延伸）。

**至少一个可见即时后果选择**：A/B 即时改变砚秋水随后交出的"账本第一笔"内容，并置 **篇内 flag `s1x03_ledgerTone`**（principle-driven / trust-driven），影响收束段账本扉页题词。flag 仅存本篇。

**局部收束与成员后续态度**：四组成立结果不变；差异在玩家对"规则型组织"的认同基调。返回点：补遗列表。

**设计约束**：不回写 `r4-00-founded`/`r4-01` 的序章结果；不新增四组主线节点；砚秋水动因仅作 adapted 补全。

**建议节点骨架（s1x-）**：
```
s1x03-entry        → 四组·创立前夜（玩家独白：砚秋水找我）
s1x03-player-ask   → A 问立组 / B 问为何是你（set s1x03_ledgerTone）
s1x03-yanshuii-answers → 按 choice 分支（adapted 动因）
s1x03-ledger       → 账本扉页题词差异
s1x03-close        → 返回补遗列表（set s1x03_done）
```

## S1X-04 · 五组《第一天就走了的人》

**路线**：五组·未闻花名（战败仍存）
**锚定缺口**：`r5-01-shi-leaves` 时 7/19 离开五组，转组申请未填公开理由（优先级①）。
**事实标签**：`adapted`（时转组为确认事实；本篇为失去方视角补全，与 S1X-01 共享统一动因）。
**消费既有事实**：`r5-01-shi-leaves`（时离开空位）、`r5-02-response-to-shi`（温陷回应）、`r5-17-after-transfer`（后续核心离开的余波背景）——仅引用。
**成员可理解立场（与 S1X-01 统一）**：时离开五组，不是不认可温陷，而是五组成立当天连"要成为什么"都没定；同一周他转进二组，是因为二组那边给了"确定性"。温陷作为失去方，表面平静、内里是不甘与自省。

**玩家可行动**：玩家作为五组侧（温陷视角或共情视角），在时离开后第一次打开时的告别留言。两选一：
- **A 放他走**："去你能扎根的地方。" → 时留言更坦诚，温陷得到释然。
- **B 问他为什么**："至少告诉我原因。" → 时留下 adapted 动因（与 S1X-01 一致的"确定性"动因）。

**至少一个可见即时后果选择**：A/B 即时改变时留言文本与 **篇内 flag `s1x04_shiReasonShared`**（true/false），并影响温陷收束独白（放下 vs 仍想证明五组也能给确定性）。flag 仅存本篇。

**局部收束与成员后续态度**：时离开结果不变；差异在温陷作为首领的余波态度（是否更坚定"未闻花名"要补齐自己的确定性）。返回点：补遗列表。

**设计约束**：不回写 `r5-01` 离开结果；不新增五组主线节点；时动因须与 S1X-01 一致，禁止矛盾。

**建议节点骨架（s1x-）**：
```
s1x04-entry        → 五组·时走后的空位（温陷/玩家独白）
s1x04-player-choice → A 放他走 / B 问为什么（set s1x04_shiReasonShared）
s1x04-shi-message  → 按 choice 分支（与 S1X-01 动因一致的 adapted 文本）
s1x04-wenxian-close → 温陷余波独白差异 + 返回（set s1x04_done）
```

## S1X-05 · 六组《第六个为什么》

**路线**：六组·{{sixthOrganizationName}}（反对旧秩序）
**锚定缺口**：`r6-00-founded` / `r6-01-recruitment-pitch` 玩家（首领）创立第六组的动因未落地（优先级①；**唯一由玩家自身即动机主体**）。
**事实标签**：`adapted`（创立事件为确认事实；本篇让玩家在隔离篇章中表达/决定创立动因）。
**消费既有事实**：`r6-00-founded`（yyT 说名字是你建的、首领你当）、`r6-01-recruitment-pitch`（招募文案三选项）、`r6-13-yyt-qifu`~`r6-17`（反对旧秩序主线）——仅引用。
**成员可理解立场**：yyT 与 AVUCII 把首领交给玩家，是因为玩家敢"开服五十元、反对前五组现成故事"；但他们也想听玩家自己说清楚——第六组到底反对什么。

**玩家可行动（强可行动，动机主体即玩家）**：在创立那一刻，玩家定义第六组"反对的具体旧秩序"。三选一：

**至少一个可见即时后果选择**：A/B/C 即时改变 yyT 递来的"章程第一页"措辞，并置 **篇内 flag `s1x05_charterTone`**（anti-story / anti-authority / anti-exclusive），影响收束段六组对外宣言的语气。flag 仅存本篇。

**设计约束**：不回写 `r6-00`/`r6-01` 的创立结果；不新增六组主线节点；玩家选择仅作用于本篇章程措辞，不向主线结局反向写入。
