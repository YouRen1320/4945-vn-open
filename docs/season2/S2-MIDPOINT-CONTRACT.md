# S2 中点合同（Midpoint Contract）

> 合同：[SOL-PLAN-2.5 §2.2]。本文件冻结 2.5 的共享中点事实与后置要求。

## 中点事实（canon，已架空拟定）

- 北岸评议委员会在评议落槌一周后宣布：下一阶段由「联合对峙」代替书面自评。
- 各组织须公开站队，并派人进入新设的「联席协调席」。
- 前半季所有选择（s2Stance / s2Diverge）将被摆到台面对质。

## 后置要求（中点必须做到）

1. 回答前半季一个核心问题：你选的边到底把你带向哪。
2. 揭示/确认改变行动方向的信息：玩法从「写稿」变为「公开对峙 + 协调席」。
3. 迫使玩家重新排序优先事项（守成 vs 翻局）。
4. 形成后半季可执行新目标：进入联席协调席。
5. 不提前解决最终危机（2.7/2.8 才触及）。

## 持久状态

- `variables.s2Midpoint` ∈ { guard, pivot }，由 2.5 回应写入，2.6 回收。
- `variables.s2Diverge`（2.4）在本集被读取并演出后果，不在本集改写。
- `variables.s2Stance`（2.3）在 2.5 以“硬话被追责 / 联署页被追责”两种现场回响再次消费；旧档缺值进入中性记录节点。
- `variables.s2RoutePressure` 记录所在组织进入协调席时的具体争议物件，供 2.6—2.7 连续使用。
