- **序章时点**：`2026-07-21` 苏铭事件；桥接篇结束后，于 `2026-09-05` 进入联合活动室。

## 3. 活跃 / 退出 / 新增组织与路线

- **活跃路线**：`org2`~`org6` 五条路线全部从序章合法进入。8 月后 org2–org5 分别使用“云梦仙踪 / 虚妄月华 / 镜花水月 / 心之所向”；org6 保留玩家自定义名。
- **退出路线**：无（序章不关闭任何 S1 路线）。
- **新增组织/路线**：本季**不新增新 route id 或 `org7`**；新增的仅是跨组织公共机构「北岸评议委员会」（作为剧情势力，非可玩路线）。2.3–2.9 继续使用 org2–org6 五条活跃路线。
- **角色职责变化**：心跳成瘾转任一组首领；路人K接任三组首领；铁碎牙任四组首领，砚秋水继续负责制度与标准说明；温陷退游后困醒任五组首领，剑问白玉京继续承担日常与外联事务。涉及组织最终决议时，由铁碎牙或困醒签字承担，不把执行负责人误写成首领。本批不扩写剧情演员的恋爱线。

## 4. 角色可用性（可使用 / 回归 / 新增 / 不可用）

- **可使用**：第一季全部已登场角色，按玩家所属组织与关系层级在序章中以合适身份出现。
- **回归**：`mentor`（评议顾问）、`bottle`（老友/情报）、玩家所属组织的 S1 队友。
- **新增**：新增苏铭、路人K、宇智波带土、铁碎牙、困醒为桥接篇剧情演员；他们不是新路线、恋爱角色或外部评议委员。
- **不可用**：除上述经素材确认的桥接篇演员外，不再根据文件名自动启用其他具名角色；外部评议委员以「系统/群聊」匿名身份呈现，不绑定具体 CharacterId。

## 5. 第一季结果继承级别

- 继承字段分 `flavor` / `scene` / `structural` / `ending` 四级（详见 S2-INHERITANCE-CONTRACT.md）。
- 序章继承：**route / organization / 单线伴侣（若有）/ 关系层级（0–100）** 为 `structural`；**组织结局 id** 为 `ending`；**具体对话措辞** 为 `flavor`。
- 序章**不得擅自扩大级别**（如把 flavor 提升为 structural）。

## 6. 公共主冲突、玩家目标与不可改写事实

- **主冲突**：北岸评议委员会要求各组织提交年度联合自评，并暗中将评议结果与前程资源挂钩，引发组织间的紧张与玩家内部的站队压力。
- **玩家目标（序章形成）**：在「维护所在组织立场」与「不破坏既有关系」之间作出公开表态，并就「是否接受联合活动室牵头」给出第一个具即时结果的选择。
- **不可改写事实**：第一季已确定的 route / organization / 伴侣 / 组织结局；评议委员会作为外部压力存在，其具体裁决结果不在此季内定论。

## 7. 失败状态、主要结局与关系收束结构

- **失败状态**：序章无硬失败；若玩家在评议上完全回避表态，序章仍以「暂缓表态、问题待解」收束并标记 prologue 完成（不导致季终失败）。
- **主要结局**：本季主要结局（关系/组织）在 2.3+ 展开；序章仅建立「联合评议代表」目标与一条初始关系张力。
- **关系收束结构**：序章可在玩家既有伴侣（若有）或最亲密队友上埋下一条「跨组织距离」张力，作为后续季的关系收束伏笔；不构成结局。
