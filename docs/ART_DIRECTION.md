# 《4945区》二维 Galgame 美术与演出规范

## 目标

第一季采用传统日式视觉小说的二维角色主导画面。核心体验不是统计“完整大图文件数”，而是让玩家每一至三次点击都看到人物、表情、站位、镜头、聊天状态、游戏状态或事件插图中的至少一种有意义变化。

目标资源规模：

- 300—500 张经人工检查的生成母图；
- 60—80 个背景构图，并提供昼夜、气氛或事件状态变体；
- 80—120 张事件 CG，每张提供 2—4 个剧情差分；
- 核心角色具备 2 套服装、3 个基础姿势、6—8 个表情；
- 通过人物分层、表情、站位、明暗、镜头与剧中 UI 组合出 3000 个以上可见画面状态。

## 统一画风

- 精确的深色彩线稿，使用清晰的赛璐璐明暗分块；
- 人物五官、发型、服装和代表饰品以角色锚图为唯一身份基准；
- 角色采用青年或成年比例，不使用幼态、擦边或夸张身体表现；
- 色彩明快但受控，背景服务人物，不使用半写实电影概念图；
- 不使用 3D 渲染感、摄影质感、通用赛博朋克霓虹或无意义粒子墙；
- 图片中不生成对白、昵称、数值和菜单文字，所有文字由 HTML 渲染。

## 画面构成

### 普通剧情

二维背景叠加一至三名透明立绘。角色可以处于左、中、右位置，并通过表情、姿势、明暗和焦点区分当前说话者。

### 剧中 UI

私聊、群聊、世界频道、成员列表、排行榜、要塞 HUD、奖励记录和系统公告使用独立的 HTML 界面。角色头像只在这些界面中作为身份元素，不再放大成圆形“立绘”。

### 事件 CG

重大历史节点、关系转折、路线成立与结局使用全屏插图。桌面与横屏显示完整 16:9 画面；竖屏优先使用中央安全区裁切，关键 CG 后续提供专门竖屏裁图。

## 移动端规则

- 375px、390px、430px 竖屏必须完整可玩；
- 人物面部和关键动作位于中央 55% 安全区；
- 竖屏时舞台约占上方 62%—70%，对话框固定在下方安全区；
- 所有触控目标不小于 44×44px；
- 横屏和桌面恢复传统 16:9 Galgame 构图；
- 资源按章节懒加载，首屏只预载标题、建档、序章第一场和常用角色。

## 东方元素

东方元素用于章节牌、符卡式标题、结界转场、弹幕轨迹、符纸纹样和组织徽记，不直接复制既有角色或场景。现代 QQ 群、手游客户端与东方式包装形成视觉反差。

## 角色一致性流程

1. 读取头像、人物设定和剧情职责；
2. 生成一张全身中性锚图；
3. 去背并检查发丝、手部、服装和代表饰品；
4. 以锚图派生姿势与表情，禁止重新设计人物；
5. 事件 CG 必须引用锚图；
6. 不通过一致性检查的图片不进入 `public/assets`。

## 当前锚点

### 夏娜

- 长玫瑰粉发、酒红眼、金色几何发夹；
- 象牙白高领内搭、炭黑蓝短外套、暗玫瑰滚边、不对称裙裤与短靴；
- 克制、务实、直接，画面气质是冷静承担后果，而不是寻求冲突；
- 标准立绘：`game/public/assets/sprites/shana/base-neutral-v1.png`；
- 事件 CG：`game/public/assets/cg/jiangnan-planning-v1.webp`。
