# 《4945区》3.4 Sol 方案：第三季首次不可逆承诺与路线分歧

> 状态：条件 Sol 方案；具体承诺内容依赖 3.2 canon 与 3.3 结束状态。
>
> 发布性质：第三季第一个持续改变后续过程的结构分歧单元。
>
> 前置：[3.3 多季余波落地与新目标](./SOL-PLAN-3.3.md)。
>
> 后继：[3.5 旧选择后果与中点重构](./SOL-PLAN-3.5.md)。

## 1. 目标与范围

3.4 让玩家对第三季新目标作出第一次不可逆承诺。选择必须改变后续至少一项：公开立场、合作关系、可用手段、承担责任、失去的资源或下一段场景结构；不能在几段台词后无痕合流。

“不可逆”不等于立即锁死最终结局。玩家仍可在后续改变策略或承担代价，但系统和剧情不能假装这次承诺从未发生。

## 2. 剧情单元合同

### 2.1 承诺形成

- 3.3 建立的竞争优先事项转化为可行动冲突；
- 不同人物或路线提出合理但无法同时满足的要求；
- continuity profile 可以改变可用语境、资源或代价，不能替玩家自动作答；
- 所有选项说明可理解的风险类别，不展示隐藏公式。

### 2.2 实质分歧

每条活跃路线至少一个承诺选择满足：

- 有稳定 `s3-` choice ID；
- 本集内展示即时结果；
- 至少一个状态持续到 3.5；
- 选择改变行动结构，而非只改称呼或数值；
- 每个合法 continuity class 有选项或明确 fallback；
- 不跳入未发布 episode 或提前判定主要结局。

### 2.3 阶段收束

本集回答“玩家愿意以什么立场和代价推进第三季目标”，并展示第一轮收益与损失。集末的持续状态必须可在人类可读的季/集摘要中辨认。

## 3. 分支与继承预算

每个结构分歧登记：

```text
branchId
routeScope
choiceIds
continuityInputs
immediateDifference
persistentState
rejoinPolicy
payoffRelease
fallback
testClasses
```

规则：

- 第三季 route state 与 continuity inputs 分层，不预生成全部组合节点；
- structural/ending 等价类穷举路径；
- scene 类按场景族覆盖；
- flavor 类用代表组合与快照测试；
- 新增一个结构维度必须说明其后续回收成本和合流/退休策略；
- 未能承诺测试与回收的分支不得进入稳定版本。

## 5. 验收标准

1. 每条活跃路线都有至少一个不可逆承诺，改变行动结构或持续代价。
2. 每个承诺在本集展示即时结果，并把持续状态登记给 3.5。
3. continuity 只改变语境、资源或代价，不自动替玩家选择。
4. structural/ending 等价类全部可达并有自动路径，scene/flavor 覆盖符合预算。
5. payoff ledger、branch budget、节点图和实际状态字段一致。
6. 任一合法 profile 均有完整路径，非法组合不落入隐藏默认值。
7. 前两季、3.1–3.3、outcome archive 和离线季包零回归。
8. 本版素材 ready，类型检查、单测、内容图、构建、E2E 和设备验收通过。

## 6. 迁移与回滚

本版不升级 schema。回滚到 3.3 时保留 3.4 承诺状态；旧版本显示需升级或停在安全入口，不能撤销、重选或猜测承诺。重新升级后恢复原分支。

## 7. 兼容性妥协

- 部分分支会在后续合流，但持续代价和回收点保留。
- flavor 组合不做全路径穷举，使用代表组合与确定性 fallback。
- 为控制长期债务，不是每个前代结果都能提升为结构分支。

## 8. 有意不做

- 不提前实现 3.5 中点后果、3.7 最终危机或主要结局。
- 不允许完整前代存档字段进入分支条件。
- 不新增 canon 外结构维度。
- 不生成图片或用低差异视觉堆数量。

## 9. 退出闸门

所有承诺、即时结果、持续状态、组合预算、正式素材和回归通过后 3.4 才可发布。无法明确回收的结构分支必须缩减或删除。
