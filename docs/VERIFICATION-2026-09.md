## 已知情况

- 生产构建的主 JavaScript 包约为 1,289 KB（压缩后约 361 KB），已超过 Vite 的默认体积提示阈值。当前不影响构建通过，但后续可单独评估代码拆分；本次不混入无关重构。
- 当前存档仍使用 `localStorage`。是否迁移到 IndexedDB 必须以容量、原子性和回滚证据为依据，不因版本规划而自动迁移。
- 网站型发布没有附加 GitHub Release 二进制资产；线上版本由站点交付。
