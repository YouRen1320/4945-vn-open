# v1.5.0 · 全员夜话、关系进度与心跳支援

## 本次完成

- 关系候选扩展为 12 人：祈福、夏娜、心跳成瘾、砚秋水、温陷、辰逸、剑斩凡人心、华月乌大王、takemehand、希露菲、yyT、AVUCII；终局由玩家显式选择，不再依赖隐藏优先级自动抢结局。
- 五条组织路线加入可选“成员夜话”。当前出现的 28 名组织成员均至少有一次玩家选择和本人即时回应；蓝确认为二组成员，星晴确认为六组成员，并使用用户提供头像与独立立绘。
- 二组补齐辰逸在失去权限后的责任与关系线；六组补齐 yyT、AVUCII 的独立关系线。新增 `权限之外`、`强硬之后`、`最后一行留空`三张关系 CG。
- 三组新增架空的将进酒白猫灵兽支线。契约需要明确同意、可随时解除、天亮自动失效，且不改变人物人格与发言权；新增 `白猫符约` CG。
- 所有关系候选获得可见的 0—100 攻略值。心跳成瘾达到 100 后解锁“心跳支援”：每幕一充能，下一次选择实际增加声望与凝聚各 1；攻略值不消耗，属性全满时也不浪费充能。
- 状态、存档、历史、设置与图鉴弹窗补齐 Escape、Tab 焦点圈和焦点归还；隐藏文件输入不会进入键盘焦点。
- 手机竖屏与横屏统一 44px 触控目标，聊天回复、经典选项、存档操作、顶部与快捷控制都能单手可靠点击；顶部支援按钮不会遮挡选择区。
- 对话逐字层与屏幕阅读器播报分离，完整文本只播报一次；聊天、系统、战斗和经典对白由各自舞台独立承载，不再叠加重复 UI。

## 存档与回滚

- 存档 schema 升至 3，应用与 Service Worker 缓存键升至 `1.5.0` / `4945-v1.5.0-r1`。
- v1.5 只写 `4945-vn:v3:save:*`，旧版 `4945-vn:save:*` 仅作为只读迁移来源，不会被覆盖。损坏的 v3 记录会回退读取旧记录；玩家显式删除存档时才同时删除两代记录。
- v1/v2 存档会补齐关系进度、蓝、星晴和支援字段。已经满足 v1.4 关系结局门槛或已经解锁结局的玩家会迁移为对应攻略值 100，不会因新进度门槛失去原有资格。
- 回滚到 v1.4 时，玩家能继续使用最后一份 v1.4 检查点；v1.5 期间新增的进度只由 v1.5 及后续版本识别。重新发布 v1.5 即可恢复该进度。
