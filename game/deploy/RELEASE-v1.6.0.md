# v1.6.0 · 幻想夜市、正式约会与恋爱日常

## 本次完成

- 12 名关系候选全部获得独立的首次约会、正式告白和交往后日常：夏娜、祈福、辰逸、剑斩凡人心、心跳成瘾、砚秋水、华月乌大王、温陷、takemehand、希露菲、yyT、AVUCII。
- 新增 36 个稳定剧集入口与 120 个恋爱剧情节点。每条首次约会和日常都有两项具体行动与角色即时回应；告白可以接受或暂缓，不把“继续了解”写成失败结局。
- 游戏内新增“羁绊与约会”舞台：12 人头像横向切换、角色立绘、可见攻略进度、叙事化阶段文案与单一主要行动。达到资格时，顶部心形入口与暂停菜单都会提示新邀约。
- 每个存档只允许确认一名恋爱伴侣；其他对象仍作为朋友与同伴保留。交往后的日常可以重温，但重复游玩不重复增加关系值。
- 约会支线会记录进入前的主线节点，完成后返回原位置，同时保留主线日期与章节，不改变第一季固定历史节点。
- 新增四张内部图像模型生成并人工检查的正式夜市场景：月门、妖怪食街、符卡游艺场、河灯桥。不同角色的首次约会、告白与日常按地点使用对应场景，不再复用“深夜消息”背景。
- 场景鉴赏新增四张夜市背景；图片统一为 1672×941 WebP，中央保留立绘安全区、底部保留对白区。
- 聊天舞台改为从输入区向上排列短消息；新节点和新回复自动回到底部，玩家主动上滑回看时不会被打字动画抢走滚动位置。装饰性标题图标不再造成误触或错误焦点。
- 手机端 375×812 与桌面 1440×900 的羁绊页、约会场景、选项和立绘均完成真实截图检查；主要触控目标保持至少 44px。

## 存档、迁移与回滚

- 存档 schema 升至 4，应用与 Service Worker 缓存键升至 `1.6.0` / `4945-v1.6.0-r1`。
