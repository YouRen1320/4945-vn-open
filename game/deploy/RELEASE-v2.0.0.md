# v2.0.0 · 第一季章节回放与路线沙盒

## 本次完成

- 通用回放内核：关系回忆与章节沙盒共用同一套隔离回放会话（ReplayKind = romance | chapter，ReplayOrigin = title | game-snapshot），统一负责隔离、退出与错误恢复，不再维护第二套平行实现（SOL-PLAN-2.0-3.0 §5）。
- 标准检查点注册表：31 个类型化配方（1 个共通序章 + 五条路线各六章节），全部从 `createInitialGameState` 构建，按 route 显式设好 route / organization / organizationName / role，再 enterNode 入口节点，由节点的 onEnter 与 chapter/date 字段补齐本幕状态；绝不粘贴完整旧存档。
- 标题页新增“章节回放”入口：当全局收藏存在任一组织结局后显示；进入章节选择面板，可选玩家名，六组沙盒可额外填写本次使用的组织名（不写入存档）。
- 解锁门控：每条组织路线在收藏中存在该路线任一组织结局后解锁；共通序章始终可用。
- 隔离不变量：回放完成、主动退出、异常或刷新后，自动存档、六个手动存档、收藏、设置与当前正常游玩状态逐字节不变；回放期间保存、读取、导入、新游戏和再次进入回放均被统一阻止或先显式退出。
- 关系回忆迁移：原有关系回忆改走通用内核，行为与 1.9 完全一致，全量回归矩阵已验证。
- 抵达季终节点 `credits-first-season` 自动退出章节回放，回到章节选择；刷新只结束内存回放并回到标题页。

## 发布隔离

- 本版本从主工作区以隔离构建产出，只带 2.0 回放内核、检查点注册表、章节选择 UI 与版本说明。
- 1.8 视觉内容（36 项托管视觉）仍处于暂停状态，本次发布不混入未完成剧情或图片；2.0 不触碰 1.8 视觉素材。
- 第二季内容不在本次范围；schema4 / v4 存档、第一季节点与结局 ID 全部保持不变。

## 存档、兼容与回滚

- 应用版本升至 `2.0.0`，Service Worker 缓存键随之更新。
- 存档 schema 保持 4，存档键保持 `4945-vn:v4:save:*`；收藏键保持 `4945-vn:collection`。已有剧情、关系、收藏与伴侣状态无需迁移或重置。
- 章节回放是纯沙盒，不写任何存档、不合并收藏、不解锁结局或奖励，也不复原玩家过去的个人选择。
