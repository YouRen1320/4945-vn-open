## 3. 隔离不变量（已通过测试覆盖）

补遗复用 2.0 通用隔离回放会话（`season1-supplement` 类型，origin `title`）：不写存档、不合并收藏、不发奖励、不允许嵌套回放。

- 抵达返回哨兵 `s1x-exit` 时，仅把**收束节点 id**（如 `s1x01-close`）定向追加到收藏 `seenNodes`（`appendCollectionSeen`），不回写任何组织结局、关系值或来源存档。
- 回放完成、主动退出、刷新或异常后，自动存档、6 个手动存档、收藏（除定向完成标记外）、当前游玩状态逐字节不变。
- 完成标记**幂等**：重复游玩同一篇、`seenNodes` 中该 id 仅出现一次；提前退出不写任何完成标记。
