# 2.2 图片提示词（V2.2-IMAGE-PROMPTS）

> 关联：SOL-PLAN-2.2 §9.9；`game/docs/V2.2-ASSET-MANIFEST.md`。
> 结论：**2.2 共通序章阶段无需任何新生成图片**，因此本文件暂为空载提示词模板，仅记录复用约定与未来扩展位置。

## 1. 序章图片策略：零生成

第二季共通序章（`s2-prologue-*`）全部复用第一季既有资产：

- 背景键 `organization` / `warRoom` / `aftermath` → 既有母图，无需生成。
- 角色 `bottle` / `mentor` → 既有立绘，无需生成。
- 无专属 CG；`historical: 'fictional'` 仅标记剧情架空属性，不影响资源。

因此 `audit:assets`（普通）与 `audit:assets:final` 对序章均通过（无待生成项）。

## 2. 未来 s2 集扩展提示词（占位模板）

当 2.3+ 引入专属 s2 CG / 背景时，按以下结构追加条目，并同步至 `V2.2-ASSET-MANIFEST.md`：

```
### s2-<episode>-<scene>-cg
- 键：<background 或 cg 引用键>
- 提示词：<与既有 v1.8 CG 提示词风格一致的中文/英文提示词>
- 规格：≥1600×900、16:9±1%、≤500 KiB WebP
- 继承级别：<flavor|scene|structural|ending>
- 来源：第一季 outcome 摘要字段 <durableFact / route / org / partner>
```

## 3. 一致性约束

- 所有新提示词必须复用既有视觉语言（见 `artifacts/imagegen-v18/` 提示词文档与 `docs/ROADMAP` 资产约定）。
- 新增 CG 须经 `package:v18-cgs` 打包、`qa:v17-cgs` 规格校验、`audit:assets:final` 全就绪后方准入 3.0 稳定发布。
- 不新增 `CharacterId` 的立绘（第二季约束：仅复用既有角色）。
