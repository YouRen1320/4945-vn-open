## 正式发布门禁

以下条件必须全部满足，才能把 v1.8 视觉状态从预览改为正式：

1. 36 张文件全部到位，并逐项把 `visualAssets.ts` 中对应状态从 `pending` 改为 `ready`。
2. `npm run audit:assets:final` 通过；任何缺图、仍为 pending、错误尺寸、无效 WebP 或超限文件都会失败。
3. 12 张 CG 与 8 张背景至少 1600×900、16:9±1%、单张不超过 500 KiB；16 张表情立绘至少 800×1600、竖版、单张不超过 300 KiB。
4. 人工检查角色身份、手部、无文字水印、中央手机裁切、底部 30% 对白区和表情切换不跳位。
5. 完整离线缓存后断网重进，12 条告白、8 个背景变体和 16 张差分均返回真实图像响应。
