# v1.7.2 稳定性收口验收

## 范围

本补丁版本只收口已经实现并验证的稳定性问题，不提前包含 v1.8 的正式视觉成品，也不改变 schema4 / v4 存档合同。

## 已完成

- 生产资产审计排除测试源码中的故意虚构 URL，避免把测试夹具误报为缺失发布资源。
- 已完成的恋爱日常允许重复体验，但关系值和完成奖励保持幂等。
- 关系回忆结束或取消时恢复精确的进入前快照，不重复写入主线历史、处理节点、收藏或存档。
- 事件 CG 在图片解码和响应式切换期间保持占位路径与提示词标识。

## 验收命令

在 `game/` 目录执行：

```text
npm run typecheck
npm test
npm run audit:assets
npm run build
```

四项均须通过。`npm run audit:assets:final` 仍然只用于 v1.8 正式视觉发布，不属于本补丁的通过条件；在 36 个外部生成素材交付前，它应继续拒绝正式发布。

## 兼容性与回滚

- 不升级存档 schema，不删除旧节点或收藏 ID。
- v1.7.1 存档继续由现有迁移逻辑读取。
- 若补丁验证失败，回滚代码即可；不需要删除用户本地存档或旧视觉资源。

## 非目标

- 不把 v1.8 占位图标记为 `ready`。
- 不在本补丁中实现 2.0 章节回看；章节回看必须先完成独立的章节起点与状态重建设计。
