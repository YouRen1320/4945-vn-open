## 5. 已知限制（仅规划 / 未验证）

- **公网发布**：本工作区不直连服务器，未做真实公网部署与离线更新演练；"线上已验证版本"仍只能记录到本地候选，不能声称公网稳定版。
- **图片生成**：v1.8 托管视觉 32 项 `pending` 由用户使用外部模型生成，2.0 以回退呈现；这些项须在后续发布规划前被标记为指定版本 / 明确延期 / 取消，不能继续无归属悬空。
- **e2e 浏览器环境**：本沙盒首次安装 Chromium 后实跑通过；CI 复跑需保证浏览器可用。
