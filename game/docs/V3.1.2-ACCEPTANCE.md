## 兼容与迁移

- 保留内部 `season2`、`s2-*`、schema4/schema5、v4/v5 存档与既有 localStorage 键；本版没有数据迁移。
- 玩家可见文案统一为“事件一 / 事件二”，内部稳定标识不重命名，以免破坏存档和剧情图引用。
- 事件二建立成功后仍清理陈旧事件一自动档，避免标题“继续主线”重复进入片尾。

## 明确排除

- 不开始事件三或其他新剧情设计。
- 不合并 v4/v5 底层存档格式。
- 不在本次体验修复中进行 JavaScript 分包。
- 不在本次版本中新增独立预发布环境；正式切换继续使用现有原子发布与回滚流程。

## 已知限制

- 主 JavaScript 包约 919 kB（gzip 约 274 kB），构建仍提示超过 500 kB；该性能工作应单独规划。
- 当前部署基础设施只有正式站点，没有独立预发布域名或不切换 `current` 的测试发布流程。
